## 3. 里程碑周级拆解

### M1：多 Agent 最小集 + 基础链路（2026-07-13 ~ 07-31，3 周）

| 周 | 内容 | 需求项 |
|---|---|---|
| W1（07-13~17） | 工程脚手架（FastAPI + LangGraph + Celery）；LLM 适配层：多模型接入、OpenAI 兼容协议、模型配置管理、任务级切换、Vision 标识；纯文本/Word 解析 | F-1-1~5、F-2-2/4 |
| W2（07-20~24） | PDF 解析（含扫描件 OCR）；**主控 + 生成 + 评审三角色最小编排**（拆解→生成→评审→修正回环 ≤3 轮）；测试专家 Prompt 与方法论内置；内置默认模板 | F-2-1、F-3-1/2/6、F-4-2 |
| W3（07-27~31） | Excel 导出；容错与降级（重试/备用模型）；文件限制校验；端到端联调 | F-5-2、F-1-6、F-2-8 |

**出口标准**：上传 Word/PDF/文本 → 生成默认模板 Excel 用例全链路走通；≥3 家模型接入且任务级可切换（验收 1、3、6 初验）；生成-评审分离与定点打回可演示（验收 14 部分）。

### M2：XMind + 自定义模板 + 图片多模态（2026-08-03 ~ 08-21，3 周）

| 周 | 内容 | 需求项 |
|---|---|---|
| W1（08-03~07） | XMind 生成（ZEN 格式 zip+content.json）；XMind/Excel 双格式内容一致 | F-5-1/4 |
| W2（08-10~14） | 模板上传与字段自动识别、字段映射确认、模板库管理；严格模板约束（不合规自动重生成） | F-4-1/3/4/5 |
| W3（08-17~21） | 图片多模态解析（OCR 兜底）、多文件混合上传、大文档分片、解析结果预览；**需求分析 Agent 独立成角色**（测试点拆解 + 盲区识别） | F-2-3/5/6/7、F-3-3 |

**出口标准**：验收 2、3、4 通过；CSV 导出（F-5-3）随 Excel 一并交付。

### M3：业务知识库（RAG）+ 知识管家 Agent（2026-08-24 ~ 09-11，3 周）

| 周 | 内容 | 需求项 |
|---|---|---|
| W1（08-24~28） | 知识文档上传、三大分类与知识空间管理、切片与向量化、Embedding 模型配置（依据 POC-R8 选型结论） | F-7-1/3/4/10 |
| W2（08-31~09-04) | 混合检索（向量+关键词）；知识自动注入与引用可见；**知识管家 Agent**：5:3:2 配额分配与让渡、分类差异化检索时机 | F-7-3b/5、F-7-6 |
| W3（09-07~11） | 历史用例入库（Excel/XMind → 测试用例库）；知识与需求冲突仲裁；任务知识快照；首批知识语料实测调优 | F-7-2/12/13 |

**出口标准**：验收 7、13 通过；知识库命中率具备统计口径。

### M4：多轮修订 + Web 界面 + 记忆系统 + 评审闭环（2026-09-14 ~ 10-09，净 3 周，跨国庆）

| 周 | 内容 | 需求项 |
|---|---|---|
| W1（09-14~18） | 多轮对话修订（主控 Agent 路由、增量更新重导出）；短期会话记忆；任务管理与异步队列完善 | F-3-5、F-8-1、F-6-1/2 |
| W2（09-21~25） | Web 界面：任务创建/进度/结果预览/对话交互；**在线评审留痕**（逐条采纳/修改/删除 + 一键反馈）；**离线评审终稿回传 diff** | F-6-6/8 |
| W3（09-28~30 + 10-08~09） | 用户偏好记忆、项目记忆、记忆检索注入（独立配额 ≤5%-10%）、记忆可见可控与纠错 | F-8-2/3/6/7 |

**出口标准**：验收 5、9、12 通过；**试点版本封版，10-12 交付试点**。

### M5：权限隔离 + 知识进阶 + 部署运维（2026-10-12 ~ 10-30，3 周）

| 周 | 内容 | 需求项 |
|---|---|---|
| W1（10-12~16） | 用户与权限（两角色 + 项目成员制）、知识空间权限隔离、记忆隔离安全 | F-6-3、F-7-11、F-8-8 |
| W2（10-19~23） | 领域术语表、缺陷经验沉淀、知识反哺闭环（来源标记防同质化）、修改习惯学习（记忆/Prompt 分工仲裁） | F-7-7/8/9、F-8-4 |
| W3（10-26~30） | OpenAPI 对外接口、日志监控（ELK + Prometheus + 告警）、Docker/K8s 容器化部署、流式输出与用量统计收尾 | F-6-4/5、F-1-7/8 |

**出口标准**：验收 8、10 通过；生产环境部署就绪。

### M6：自我学习体系（学习 Agent 离线异步）（2026-11-02 ~ 11-27，4 周）

| 周 | 内容 | 需求项 |
|---|---|---|
| W1（11-02~06） | 学习语料自动积累管道（留痕→标准化语料，含口径定义与质量过滤） | F-9-1、R10 |
| W2（11-09~13） | LLM-as-Judge 自动评估器；**黄金评估集**建设（人工精标，试点期数据取材） | F-9-2/8 |
| W3（11-16~20） | Prompt 自动优化（候选生成→黄金集回归→审批发布→可回滚）；坏案例归因分析与分发 | F-9-3/4/9 |
| W4（11-23~27） | 记忆自动提炼联动；效果度量看板；覆盖度报告；整体回归 + 全量验收 | F-8-5、F-6-7、F-3-7 |

**出口标准**：验收 11 通过；全部 14 条验收标准回归。
**顺延项**（视语料积累进度，预计 2027 Q1 启动）：模型微调 F-9-6（语料 ≥3000 条）、A/B 实验 F-9-7、逃逸缺陷学习 F-9-5（需先打通禅道/Jira 对接）。

## 5. 试点与推广（与开发并行）

| 阶段 | 时间 | 范围 | 退出标准 |
|---|---|---|---|
| 试点期 | 2026-10-12 ~ 11-20（6 周） | 1 个游戏项目 + 1 个非游戏业务线，各 2-3 名种子用户；使用 M4 封版版本，M5/M6 滚动升级 | 采纳率 ≥50%，收集高频修改模式，完成 Prompt 与知识库首轮调优 |
| 扩大期 | 2026-11-23 ~ 2027-01-15 | 试点业务线全体测试人员 | 采纳率 ≥70%，提效比 ≥50%，形成使用 SOP |
| 全面推广 | 2027-01 起 | 全测试团队，纳入日常流程 | 指标看板常态化，知识库自增长 |

> 试点期评审 SOP（R10）：种子用户必须走在线评审或离线回传通道认真留痕，否则学习语料污染，M6 自我学习地基失效。

## 6. 关键依赖与风险对排期的影响

1. **R8 Embedding POC 是 M3 的硬前置**——若 08-21 未出结论，M3 顺延，连锁影响 M4 试点封版。
2. **国庆假期已计入 M4**；若团队另有调休安排需同步修正 10-09 之后所有节点。
3. **M6 依赖试点期真实评审数据**（黄金评估集取材、语料管道验证）——试点期若延后启动，M6-W2 之后需相应顺延。
4. **三重防护不可裁剪**（R11）：黄金集回归、管理员审批、版本回滚均在 M6-W3 内，不作为可砍需求。
5. 缓冲策略：整体预留 2 周缓冲（11-30 ~ 12-11），优先吸收 M3 检索调优与 M4 前端联调的超期风险。
