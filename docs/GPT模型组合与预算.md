# GPT 模型组合与预算

更新：2026-09-25。公司已采购 OpenAI GPT，本文按**效果从最好到最差**列出可选的模型组合，并给出单任务成本与月预算，作为选型与报预算的依据。

当前云端默认：**A 顶配组合**（生成与评审都用 gpt-6-astra）。

## 2. 一个任务用多少 token

按本地 4 个真实生成任务的 AI 调用日志取均值（每任务约 11 次模型调用）：

| 环节 | 输入 token | 输出 token | 说明 |
|---|---|---|---|
| 需求拆解（测试点） | 9K | 15K | 1–2 次 |
| 用例生成 | 41K | 69K | 按模块并行，约 6 次 |
| 覆盖查漏、语义查重、驳回修改 | 9K | 10K | 视需求而定 |
| 用例评审 | 30K | 16K | 最多 3 轮，约 4 次 |
| **合计** | **约 75K** | **约 81K** | 典型任务 |

预算按「生成侧 45K 入 / 65K 出，评审侧 30K 入 / 16K 出」计算。本地日志里最大的一次任务是 123K 入 / 221K 出，作为「大任务」上限参考。

## 4. 月预算

单任务成本 × 任务数 × 1.1（需求分析、依赖识别、对话修订、图片理解等零散调用按 10% 计入）。

| 组合 | 50 任务/月 | 200 任务/月 | 500 任务/月 |
|---|---|---|---|
| A 顶配 | $264 | $1,056 | $2,640 |
| B 旗舰评审 | $101 | $405 | $1,012 |
| C 均衡 | $53 | $211 | $528 |
| F 稳定输出 | $77 | $309 | $771 |
| G 经济 | $41 | $165 | $413 |
| H 最省 | $3 | $11 | $26 |

知识库向量化按每份文档 5 万字估算，约 $0.005，可忽略。

**顶配组合按 200 任务/月报预算约 $1,100，留 30% 余量报 $1,500/月。** 大需求（十几个模块、上百条用例）单任务可到 $12 以上，若这类任务占比高，按 $2,000/月 报。

## 5. 使用与切换

- 生成任务创建时可单独指定「评审模型」，不指定时评审与生成同模型。顶配组合即两者都不指定，默认 gpt-6-astra。
- 切换组合只需在「系统设置 → 模型配置」改默认模型，任务级选评审模型；不用重启。
- GPT-6、5.6、5.5 系温度只能填 1；只有 5.4 系能用 0.3。页面编辑这些条目时不要改温度，否则调用直接报 400 并落到降级链路。
- 降级链路：gpt-6-astra → gpt-6-sol → gpt-6-luna → gpt-5.4 → gpt-5.4-nano。OpenAI 单个型号故障时自动向下，不会中断任务。
- 实际用量在「AI 中心 → 调用日志」按用途、模型、任务统计，运行一个月后用真实数据回填本表的 token 画像。
