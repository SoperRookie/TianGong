## 4. 审核工作台交互 （测试点与用例审核共用一套壳：左列表右详情，键盘驱动，撤销优于确认）

```mermaid
stateDiagram-v2
  direction LR
  [*] --> 选中一条: 进入即定位第一条待审（?sel=）
  选中一条 --> 选中一条: j / k 上下移动
  选中一条 --> 已通过: a 通过（乐观更新，行变绿，不弹 toast）
  已通过 --> 选中一条: 自动前进到下一条
  已通过 --> 撤销条: 「已通过 TP004 · 撤销」停留 8 秒，连续操作合并成「已通过 5 条 · 撤销」
  撤销条 --> 选中一条: 点撤销 → 回滚
  选中一条 --> 驳回展开: r 驳回（详情区内展开，不弹窗）
  驳回展开 --> 驳回展开: 单击类型胶囊 · 填原因 / 要求
  驳回展开 --> 已驳回: ⌘⏎ 提交
  驳回展开 --> 选中一条: Esc 收起
  已驳回 --> 选中一条: 自动前进；用例审核时顶部出现「AI 修改驳回用例」提示条（含前后对比）
  选中一条 --> 行内编辑: e 修改（标题 / 步骤表格直接改，保存即新版本）
  行内编辑 --> 选中一条: 保存 / Esc
  选中一条 --> 已删除: d 删除（入回收站）
  已删除 --> 撤销条
  选中一条 --> 多选: space 勾选 · ⇧A 全选
  多选 --> 批量条: 底部批量条：已选 3 · 通过 / 驳回 / 改模块 / 删除 / 取消
  批量条 --> 选中一条: 执行后合并一条撤销 toast
  选中一条 --> 完成: 「完成审核 → 生成用例」（待审 0 时可用，否则按钮旁写原因）
  完成 --> [*]
  note right of 选中一条
    详情区：需求来源原句 · 盲区关联 · 重复 · 依赖
    顶部提醒条「2 条盲区待处置 → 处理」
    底部状态条「本次已处理 12 / 8 分钟」
    ? 显示快捷键表 · 脑图视图是列表区的切换按钮
  end note
```

## 5. 执行面板交互 （逐条执行，结果按钮带快捷键，失败就地记录）

```mermaid
stateDiagram-v2
  direction LR
  [*] --> 当前用例: 第 1 轮 · 执行人 · 2 / 5
  当前用例 --> 通过: P
  当前用例 --> 阻塞: B
  当前用例 --> 跳过: S
  当前用例 --> 失败原因: F → 展开原因输入与截图拖放
  失败原因 --> 失败: 记录
  通过 --> 下一条: 自动跳转
  阻塞 --> 下一条
  跳过 --> 下一条
  失败 --> 下一条
  下一条 --> 当前用例: 还有未执行
  下一条 --> 结束本轮: 全部执行完 → 统计页签
  结束本轮 --> [*]
  note right of 当前用例
    左列表：● 已执行 ○ 未执行 ◀ 当前
    右详情：前置 · 步骤 / 预期并排 · 备注 / 附件
    入口：计划详情「开始执行」或工作台卡片「开始执行」
  end note
```

## 6. 反馈与后台任务 （乐观更新、全局轮询、铃铛通知）

```mermaid
sequenceDiagram
  autonumber
  participant U as 用户
  participant V as 页面（局部刷新）
  participant S as 后端
  participant N as 顶栏铃铛 / 工作台「进行中」
  U->>V: 点「发起测试设计」（使用上次设置）
  V->>V: 乐观更新：流程条 ⑤ 变「AI 拆解中 · 第 1/4 步」
  V->>S: POST 发起设计
  S-->>V: 已受理（设计记录 id）
  U->>V: 去别的页面
  loop 全局 10 秒轮询（只拉「我的进行中任务」，后续换 SSE）
    V->>S: GET 我的进行中任务
    S-->>V: 第 2/4 步 · 预计 1 分钟
    V->>N: 更新步骤与预计时间
  end
  S-->>V: 完成 · 8 测试点
  V->>N: 角标 +1「连赢前端活动页 · 8 测试点待审」
  U->>N: 点通知
  N->>V: 跳转 #/p/LY/design/:id/points?sel=TP001
  Note over V: 失败：行内「重试」，错误全文在展开行；接口错误用页面顶部横幅 + 重试，不只靠 toast
  Note over V: 加载：超过 300ms 才显示骨架屏；空状态 = 图标 + 一句话 + 一个动作按钮
```

## 8. 快捷键

全局：`⌘K` 搜索，`g w / g r / g d / g c / g p` 跳转工作台 / 需求 / 测试设计 / 用例库 / 计划，`?` 快捷键表。
工作台（审核 / 执行）：`j k` 移动，`a r e d` 通过 / 驳回 / 修改 / 删除，`space` 勾选，`⇧A` 全选，`⌘⏎` 提交表单，`Esc` 收起；执行面板 `P F B S` 通过 / 失败 / 阻塞 / 跳过。
