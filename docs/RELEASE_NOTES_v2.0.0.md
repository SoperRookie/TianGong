# 天工 v2.0.0 发布说明

- 版本：v2.0.0
- 发布日期：2026-10-14
- 标签：`v2.0.0`（dev 分支）
- 适用范围：内网部署，MySQL 8 + Python 3.12；升级与部署步骤见 `docs/服务器部署文档.md`、`docs/Docker部署文档.md`

## 概述

v2.0 的主题是「让平台认识你的业务」：任务与需求过程中的产物自动沉淀为项目知识，AI 从中提炼项目画像并在管理员确认后注入全链路，每次拆解、生成、评审都带着对业务的既有认知；需求中心、上传解析、生成质量、列表筛选分页、业务线与权限、执行管理等也做了大量完善。自 v1.0.4 以来共 70 余次提交。

## 新增与变化

### 知识沉淀与项目画像（新）

- 自动沉淀：需求原文与附件、人工确认后的 AI 需求分析结果、审核通过的测试点（含设计需求页来源）、评审通过的用例与离线终稿自动进入项目知识库，带「任务沉淀 / 需求沉淀」来源标记，按来源替换不堆积；任务 / 需求删除时联动清理、恢复时重新沉淀；项目设置可关闭。
- 项目画像：AI 从已沉淀素材提炼业务背景 / 角色与权限 / 核心流程 / 术语表 / 关键规则 / 易错点，管理员在项目工作区「项目画像」页签确认（可逐项编辑）后生效，注入拆解、生成、评审、查漏、补充测试点、需求分析全链路；每新增若干任务自动提炼待确认草稿。
- 存量回溯：项目画像页一键回溯历史任务与需求；系统管理员在知识库页可回溯全部项目；需求列表页「批量确认分析结果」把存量需求的分析结果一次确认沉淀。
- 知识库页：文档详情可查看全部切片原文（筛选高亮、分页），检索测试的命中结果点击定位到所在切片；新增「来源方式」筛选；支持导入禅道 / Jira / TAPD 历史缺陷到「历史缺陷库」并在拆解阶段注入。

### 需求中心

- 「AI 需求分析」页签重新设计：11 个分析项左侧导航，逐条编号展示、关键词筛选、分页；重新分析自动留档最近 10 次并可回看；分析结果人工确认后沉淀到知识库。
- 待确认事项分级：「必须确认」阻塞测试设计，「建议确认」可按假设继续并写入用例备注；页面明确提示为何不能开始测试设计并直达确认。
- 需求盲区闭环：逐条状态与去向（转待确认事项 / 转测试点 / 需求已说明 / 忽略 / 重开），支持全选批量处置与关键词搜索。
- 勾选多条需求合并发起测试设计；需求删除进回收站可恢复；需求原文只贴链接也能读取网页 / 图片 / PDF / Word。
- 列表筛选与分页：状态 / 来源类型 / 创建人 / 业务线，关键词扩展到补充说明与附件。

### 上传与解析

- 所有上传入口统一为累加式多文件选择（再次选择 / 拖入为追加，标签展示可逐个移除）。
- 格式全覆盖：Word / Excel / PowerPoint 全系、CSV、压缩包（zip / tar / 7z / rar，取消文件数上限）、Axure 原型导出包按站点地图逐页提取；Excel 需求按工作表自动判别文档型 / 数据型并提取内嵌截图。
- 单文件上限提高到 100MB。

### 测试设计与生成质量

- 分批审核、分批生成：任务完成后继续通过新的测试点，可只为新通过的测试点增量生成并并入现有用例。
- 失败任务断点续跑：按模块落检查点，模型欠费 / 配额用尽后「继续完成」。
- 用例表达规范固化进提示词；测试点按需求页面 / 功能点输出并带来源需求点；拆解结果解析兼容模型改写格式；分片拆解空片跳过。
- 导出：测试点导出 xlsx；用例导出固定追加「来源测试点」列；XMind 紧凑模式；导出文件与页面内容一致性校验。
- 人工测试点与 AI 测试点对比；任务列表显示测试点数量；任务支持删除 / 批量删除 / 恢复。

### 列表与交互

- 任务列表、测试计划、用例中心、我的待执行用例、项目管理、用户管理、Prompt 管理、AI 调用日志、操作日志、知识库台账全部对齐统一的筛选与分页（下拉带条数、每页 20 / 50 / 100 / 200、首尾页）。
- 页面操作后重绘保持滚动位置；用例表格步骤展开 / 收起原地切换。

### 业务线、权限与执行

- 业务线做成独立实体（增删改查，改名联动项目）；项目列表按业务线分组；各列表支持业务线筛选。
- 数据可见范围三种模式（开放 / 按业务线成员 / 按项目成员），系统管理员在用户管理页切换；任何模式下删除类操作仅系统管理员。
- 新建执行轮次可指定执行人（默认当前账号，可改派留痕）；测试计划详情增加执行历史；执行页全部展开 / 收起。

### 模型与运维

- 模型选型升级到 GPT-6（默认 gpt-6-astra，降级 sol → luna → 5.4）；Embedding 为 text-embedding-3-large。
- AI 中心显示费用与预算余额（按模型单价平台侧折算）。
- 新增 `scripts/server.sh`（启停 / 状态 / 日志 / 更新）与 `scripts/reset_data.py` 清库脚本。
- 版本号单一来源 `app/__init__.py`，`/health` 返回版本，页面侧栏底部显示。

## 升级说明

1. 按部署文档拉取 `v2.0.0` 并重启；数据库新增的文档集合（项目画像、回溯记录等）在首次启动时自动建立，无需手工迁移。
2. 新增配置项均有默认值：`TIANGONG_KNOWLEDGE_AUTO_INGEST`（默认开）、`TIANGONG_PROFILE_AUTO_EXTRACT`（默认开）、`TIANGONG_PROFILE_REFRESH_TASKS`（默认 3）。
3. 存量数据不会自动回溯，升级后建议系统管理员依次执行：知识库页「回溯全部项目」→ 需求列表页（全部项目）「批量确认分析结果」→ 各项目「项目画像」页确认自动生成的草稿。回溯会调用 Embedding 接口，耗时与历史数量成正比，期间不影响正常使用。
