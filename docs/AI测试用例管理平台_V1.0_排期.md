## 3. 里程碑明细

### M1 平台底座与权限（08-31 ~ 09-11，2 周）
> 对应第 3/4/22 章 · P0

- 用户资料补齐：姓名/邮箱/手机号/头像/状态（禁用即会话失效）/最后登录时间与 IP
- **系统级角色与项目级角色分离**：项目成员管理（项目管理员/测试负责人/测试人员/只读）
- **接口级项目数据隔离**：全部业务接口校验"当前用户 ∈ 当前项目 + 对应权限"，封禁跨项目 ID 访问
- 项目字段补齐：编码/负责人/状态（进行中/暂停/归档+恢复）/收藏/最近访问/快速切换，顶部常显当前项目
- 版本管理（名称/编码/日期/状态）、模块树管理（≤5 级、排序/移动、被引用禁止物理删除）
- 页面结构对齐第 22 章：工作台/项目/需求中心/测试点/用例库/测试计划/测试执行/AI 中心/数据统计/操作日志/系统管理

交付验收：两个项目、不同角色账号互访被正确隔离；版本与模块树可维护。

### M2 需求中心与追溯链（09-14 ~ 09-25，2 周）
> 对应第 5/6(字段)/21(数据层) 章 · P0 —— **含数据模型重构与存量迁移，是全期风险最高的里程碑**

- 需求实体化：需求列表/标题/原文（永久保留）/描述/来源/附件/状态，挂版本与模块
- 原始需求分层保护：原文 → 解析结果 → AI 分析 → 人工补充，各层独立可追溯
- AI 需求分析升级为 11 项结构化输出（功能点/业务规则/…/风险点/待确认事项），**待确认事项确认后才继续设计**（AI 禁止脑补规则已有提示词基础）
- **追溯链补齐**：测试点挂 需求ID/模块ID；用例挂 来源测试点ID/需求ID；测试类型枚举对齐；来源标记 AI/MANUAL/AI_APPEND
- 评审流转补"草稿→提交评审→待评审"环节
- 存量数据迁移脚本（97 个历史任务 → 新模型）编写与演练

交付验收：REQ→TP→TC 正反向可点击追溯；历史任务迁移演练通过。

### M3 评审深化与版本安全（09-28 ~ 10-16，3 周含国庆）
> 对应第 7/9/10/11/14(回收站) 章 · P0

- 驳回反馈结构化：驳回类型（多选）+ 驳回原因（必填）+ 修改要求 + 修改范围（当前项/选中项/只补遗漏/重生成）
- **用例字段级/步骤级驳回定位**（指定字段、指定第 N 步），AI 最小修改原则
- **AI 修改确认流**：生成新版本（不覆盖）→ 差异展示 → 接受/拒绝/继续 AI 优化/人工编辑 → 确认后重新提交评审
- 测试点/用例完整版本历史（AI 原始/人工修改/AI 修改/终稿），按权限恢复
- 多人并发：乐观锁（version 冲突提示）+ "某某正在编辑"提示 + 管理员解除占用
- 核心数据逻辑删除 + 回收站 + 恢复 + 管理员永久删除

交付验收：30 条中驳回 5 条场景——AI 只动 5 条、产新版本、人工确认后过审；两人并发编辑冲突被拦截。

### M4 测试计划、分配与执行增强（10-19 ~ 10-30，2 周）
> 对应第 12/13/14 章 · P0

- 测试计划实体（名称/负责人/周期/状态），只能选"已通过"用例，支持模块/优先级/标签筛选批量加入
- **用例快照**：加入计划即快照，正式用例后续修改不影响历史计划
- 任务分配：按模块/按用例/批量/重新分配（留痕原执行人/新执行人/操作人）；"我的执行任务"
- 执行挂到计划（现有执行轮次迁移为计划执行），执行附件：图片/视频/日志/压缩包（上传人/时间/关联记录）
- Excel 导入：上传→解析→预览→校验→逐行错误提示→确认导入（错误禁止静默导入）；人工新增用例、复制用例
- 批量补齐：改优先级/标签/模块、批量加入计划、批量分配、批量删除（二次确认）

交付验收：建计划→快照→分配→执行（含附件）→改正式用例不影响计划快照；含错 Excel 导入被逐行拦截。

### M5 AI 中心、统计与审计（11-02 ~ 11-13，2 周）
> 对应第 15/16/17/18/20/21(视图) 章 · P0 收尾 + P1 主体

- Prompt 管理：版本化存储（类型/内容/状态/创建人），**每次 AI 任务记录使用的 Prompt 版本**；AI 任务中心页（类型/状态/失败原因/重试/部分成功明示）；AI 调用日志（服务商/模型/输入输出对象/发起人/项目）
- 知识库三层：公共（显式标记方可跨项目）/项目/模块；收紧跨项目检索兜底
- AI 质量统计：测试点/用例采纳率、直接通过率、修改率、驳回率、驳回原因分布（数据留痕已齐备）
- 操作日志页（业务留痕聚合展示）+ 系统安全日志（登录/失败/IP/UA/权限变更/批量操作）
- 我的工作台（待评审/待修改/待执行/我的 AI 任务/最近操作）、全局搜索（按成员关系过滤）、覆盖追溯视图（需求是否生成点/点是否生成用例/用例是否入计划/是否执行）

交付验收：AI 质量统计五指标出数；任一 AI 产物可回溯到 Prompt 版本与调用记录。

### 验收周（11-16 ~ 11-20）
- 存量数据正式迁移、试点项目按第 2 章全流程走查、第 23 章 25 条核心规则逐条验收、缺陷修复缓冲
- **V1 完成：2026-11-20**（对外建议承诺 11 月底，含缓冲）

### 后续（11-23 起，P1 剩余 + P2）
- 通知中心、高级筛选（P1 剩余）
- AI 推荐优先级强化、驳回数据自动优化 Prompt（学习规则闭环已有雏形，接 Prompt 管理后打通）
- 外部需求平台/自动化执行平台对接、BUG 系统按需接入（P2）
